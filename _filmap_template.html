三处容易误读的地方：
① README 里旧的「文件地图」写着 13 个依赖文件、test-arbiter.html 的路由 ⓪、logo.png 被页面加载——都以本节为准（21 个依赖、路由已下线、logo 由 CSS 绘制）。
② 回归清单里 _dev/stats.js --assert 带参数，按文件名找不到 → 每次被记为「跳过（不存在）」，因此实际跑的是 50 组而不是 51 组。
③ archive-variants.js / archive-faces.js / archive-style-defaults.js / archive-learned.js 行数极少，是因为内容压成单行数据——不是空文件。

新人接手的顺序建议：① 先读 index.html 的加载顺序，弄清 21 个文件谁先谁后； ② 用 dump-out.js "一句话" 看十条真实输出的全文，比读代码快； ③ 真要改动时，先跑一次 run-all.js 记住基线，改完再跑一次对比。
