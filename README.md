# PromptLab · 视觉提示词优化工具（中 / 英）

> 输入一句中文或英文，输出一段可以直接拿去出图的提示词 —— 中文进中文出，英文进英文出。

## 这是什么

你在输入框写一句大白话，比如「一位科学家，实验室，阴天」，
它按 **九个维度**（主体 / 角色 / 场景 / 光线 / 色彩 / 氛围 / 构图 / 风格 / 质感画质）补全，
输出一段结构化、可以直接粘进 Midjourney / Stable Diffusion / 即梦这类工具的提示词。

**中英双语**：语言跟着输入走，不用切换。
中文输入出中文提示词；英文输入（`a scientist in a lab, overcast`）出英文提示词，
英文侧单独处理了冠词 a/an、短语截断和标点，不会切在单词中间。

- **2060 条词库**：角色 273 / 场景 323 / 风格 320 / 色彩 242 / 构图 220 / 光线 160 / 氛围 145 / 材质 139 / 质感 72 / 画质 12
- **两种输出**：中文提示词 / 英文提示词，自动识别输入语言（中文与日文分开判定）
- **三层降级**：规则与词库命中 → 本地向量检索（bge-small-zh-v1.5）→ LLM 兜底（可选，不填 key 就跳过）
- **纯前端 + 一个本地 Python 服务**：不开数据库、不用构建工具、没有 npm install
- **不联网也能跑**：前两层全在本地；只有「第 3 层推理」和「结构化抽取」需要 API key
- **可复现**：同一输入 + 同一 seed，输出逐字一致；点「换一版」才换

版本 V5.32，回归 50 组（`node _dev/run-all.js`）。

## 怎么跑

需要 64 位 Windows 10/11 和 Python 3.10+。

```powershell
git clone https://github.com/ZCHAOYU/promptlab-demo.git
cd promptlab-demo
pip install -r requirements.txt      # 只需一次：numpy / onnxruntime / tokenizers
python serve.py 8777                 # 或者直接双击 start.bat
```

浏览器打开 **http://127.0.0.1:8777/**（`start.bat` 会自动打开）。

> **必须走 `http://`，不能双击 `index.html`。**
> `file://` 下浏览器会拦住 `fetch`，向量检索和 LLM 都会失效，而且**不报错**，只是悄悄降级。
> 页面右上角有状态徽标：绿=正常，黄/红=正在降级。

**要不要填 API key**：不填也能出结果，只是词库里没有的写法不会去问模型。
要填的话，复制 `config.local.example.js` 为 `config.local.js`，把 `key: ''` 里填上；
或者用环境变量 `DEEPSEEK_API_KEY`。**这个文件不要提交、不要发给别人。**

**给同一 Wi-Fi 下的人用**：双击 `start-lan.bat`，按提示设一个访问码。
一定要设码 —— `/api/infer` 花的是你的 key 的钱。

仓库里已经带了向量模型（`models/`，23 MB）和预计算向量（`vectors.bin`），
clone 完不用另外下载模型、也不用跑 `precompute.py`。

## 目录里有什么

```
start.bat / start-lan.bat     一键启动（本机 / 局域网）
index.html                    主页面（必须走 http://）
serve.py                      本地服务：静态文件 + 向量 + 推理代理
app*.js / archive-*.js        五个 app 层 + 数据补丁层
entries.json / vectors.bin    词条与向量（2060 条 / 512 维）
models/                       本地向量模型（量化 ONNX，23 MB）
_dev/                         回归脚本与工具（git clone 后可直接跑）
LICENSE                       MIT + Commons Clause
```

## 常见问题

| 现象 | 原因与解决办法 |
|---|---|
| 黑窗口一闪就没 | 没装 Python 或依赖不全。用命令提示符进目录跑 `python serve.py 8777`，会打印具体报错 |
| 页面白屏 / 提示打不开 | 别双击 `index.html`。先起服务，再访问 `http://127.0.0.1:8777/` |
| 右上角徽标是黄的 | 服务没起或依赖没装好。黄灯时仍可用（纯词库拼装），只是没有向量检索和第 3 层 |
| 报 `DLL load failed` | 缺 VC++ 运行库：装一次「Microsoft Visual C++ 2015-2022 Redistributable (x64)」 |
| 端口被占用 | 换端口：`set PORT=8788` 再运行 `start.bat`（`serve.py 8788` 也可以） |
| 黑窗口里中文是乱码 | 用 `start.bat` 启动（它设了 UTF-8）；或在窗口里先执行 `chcp 65001` |
| 输入 `python` 弹出微软商店 | 那个 `python` 只是商店占位程序。到 python.org 装正式版，勾选 Add to PATH |
| 装不上 `onnxruntime` | 需要 64 位 Python。32 位 Python 装不了，换 64 位重装 |
| 第一次检索很慢 | 首次调用要加载 ONNX 模型，约 3–10 秒；之后单条查询是毫秒级 |
| 不填 key 能用吗 | 能。前两层（词库规则 + 向量检索）全在本地，只有推理和结构化抽取要 key |
| 完全断网能用吗 | 能。除「第 3 层推理」和「结构化抽取」外，其余全在本地 |
| 英文输入能用吗 | 能。中文进中文出、英文进英文出，**不用切换语言**；英文侧词条覆盖比中文少一些 |
| 改了 js 但页面没变 | `index.html` 里脚本后面有 `?v=` 缓存戳，改文件时同步改它，或者 Ctrl+F5 强刷 |
| 想换模型 | 改 `config.local.js` 里的 `model`，或用环境变量 `DEEPSEEK_MODEL` |
| 给同事 / 同一 Wi-Fi 用 | 双击 `start-lan.bat`，设访问码，把打印出来的地址和码给他们 |
| U 盘拷到别的电脑 | 用便携版（自带 Python 运行时），**先解压到硬盘**再双击，别在压缩包里运行 |
| 关掉黑窗口后服务还在吗 | 不在。服务跑在那个窗口里，关窗口即停；反过来关浏览器不会停服务 |
